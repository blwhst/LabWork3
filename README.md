# ShoeStore

## Описание

Веб-приложение для сети магазинов обуви. Позволяет клиентам просматривать каталог обуви и оформлять заказы, а сотрудникам — управлять заказами, каталогом и остатками.

## Установка

```bash
git clone https://github.com/blwhst/LabWork3.git
cd LabWork3
dotnet build
```

## Использование

```bash
dotnet run --project ShoeStore.Web
```

## Системные требования

1. .NET 10.0 или выше
2. SQL Server 2025 (уровень совместимости 170)
3. SQL Server Management Studio 22
4. Microsoft.EntityFrameworkCore.SqlServer 10.0.12
5. Microsoft.EntityFrameworkCore.Tools 10.0.12

## Контрибьютинг

Процесс участия в улучшении проекта включает следующие шаги:

1. **Форк (Fork)** — создание личной копии репозитория на своём аккаунте GitHub.
2. **Клонирование (Clone)** — скачивание проекта на локальную машину:
   ```bash
   git clone https://github.com/<ваш-логин>/LabWork3.git
   ```
3. **Ветка (Branch)** — создание отдельной ветки для правок:
   ```bash
   git checkout -b feature/<название>
   ```
4. **Коммит (Commit)** — сохранение изменений:
   ```bash
   git add .
   git commit -m "feature: краткое описание"
   ```
5. **Пул-реквест (Pull Request)** — запрос на слияние своих изменений с основным проектом через веб-интерфейс GitHub.
