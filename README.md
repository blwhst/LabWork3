# ShoeStore

Лабораторная работа №3. Веб-приложение для сети магазинов обуви.

## Описание

Приложение представляет собой сайт для сети магазинов обуви. Позволяет клиентам просматривать каталог обуви и оформлять заказы, а сотрудникам — управлять заказами, каталогом и остатками.

## Роли пользователей

- **Гость** — просмотр каталога без входа в систему
- **Клиент** — оформление собственного заказа
- **Менеджер** — работа с заказами в торговом зале
- **Администратор** — управление каталогом, остатками и пользователями

## Технологии

- Язык: C#
- Платформа: ASP.NET Core
- База данных: MS SQL Server
- ORM: Entity Framework Core
- Представления: Razor (.cshtml)
